# 인스타 연결 안내 화면에 쓸 스크린샷

여기에 `step1.png` ~ `step5.png` 를 넣으면 연결 안내 화면(InstagramSetup)의 각 단계에
자동으로 붙는다. 파일이 없으면 "화면 그림 자리" 안내 상자만 보인다 — 화면은 그대로 동작한다.

| 파일 | 무엇을 찍나 |
|---|---|
| step1.png | 인스타그램 앱 · 프로페셔널 계정 전환에서 **비즈니스**를 고르는 화면 |
| step2.png | developers.facebook.com · **앱 만들기**에서 유형을 고르는 화면 |
| step3.png | 앱 화면 · **제품 추가**에서 Instagram 을 고르는 화면 |
| step4.png | **앱 역할 → Instagram 테스터** 추가 화면 |
| step5.png | Instagram **API 설정** · 액세스 토큰이 보이는 화면 |

찍을 때 주의:
- 토큰·시크릿·이메일 같은 값은 **가린 뒤** 찍는다(모자이크나 검은 박스).
- 눌러야 하는 버튼에 화살표나 테두리를 그려 두면 훨씬 따라가기 쉽다.
- 가로 900px 안팎이면 화면에서 보기 좋다.
